# Messages

Starting texts for the reminders. Rewrite them in your family's own words and language, and have a parent approve every text before its first send.

Placeholders: `{child}` is the name or nickname your child likes, `{form_link}` is their check-in form, `{report_link}` and `{points}` come from the weekly report.

## Rules

- Short, positive, never blaming. The system reminds; the parent does not.
- One idea per line. Most people read these on a phone, so use short bullet lines instead of paragraphs.
- Use the name your child actually likes to be called.
- Nothing from private parent notes, ever.
- Messages in the parents' group are about the children, not to them. Use a heading ("{child}: weekly plan"), not "Hey {child}".

## 1. Study time (each child, weekdays after school)

```
{child}, homework time ✏️

• Start with whatever is due first
• Then a short look back at today's lessons
• Target: {study_minutes} min + {reading_minutes} min reading

Tick it off and the evening is free ✅
```

Younger child:

```
{child}, homework time 📚

• Today's school homework
• 10 min maths practice and spelling
• Then {reading_minutes} min with your book

Small steps every day 🚀
```

## 2. Check-in (each child, every evening)

```
{child}, don't forget today's check-in 📝 It takes 3 minutes: {form_link}
Mark today's topics and how well you got them, your points depend on it ⭐
```

## 3. Weekly plan (each child, Monday morning)

```
{child}, your week 🗓️

• Monday: {mon}
• Tuesday: {tue}
• Wednesday: {wed}
• Thursday: {thu}
• Friday: {fri}
• Sunday {quiz_time}: {quiz_minutes} min quiz

Homework due soonest first, then today's lessons.
Fill in the check-in every evening ⭐
```

Fill each day with the target and the reason for a short day, for example `30 + 15 (swimming)`.

## 4. Quiz time (each child, Sunday evening)

Make it fun. A theme from a show or a game your kids love works far better than "Test time".

```
🚀 Mission control calling 🚀

• Astronauts {child_1} and {child_2}, the Sunday mission starts now 📝
• Phones stay on Earth 📵
• {child_1}: {minutes_1} min, {child_2}: {minutes_2} min
• Mission complete, then the evening is yours 🌌
```

## 5. Missing check-in (parents' group, every evening, later)

```
No check-in yet today: {names}. A gentle reminder might help 🙂
```

## 6. Weekly report (parents' group, Sunday morning)

```
Weekly report is ready 📋 {report_link}

• {child_1}: {points_1}/23
• {child_2}: {points_2}/23
• Things to watch are at the top of the report
```

23 is the weekly maximum: 20 for the week plus the 3 point homework bonus.
